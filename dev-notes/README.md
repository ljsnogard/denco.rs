# 开发日志约定

本目录记录 `denco` 项目的设计决策、方案取舍与实施记录。

## 命名规则

- 文件名采用 `YYYY-MM-DD-<topic>.md`，例如 `2026-10-18-gat-and-messagepack.md`。
- 同一天同一主题的后续讨论直接追加到对应文件，不另起新文件。
- 每个文件开头用一句话说明当前结论，再按「背景 → 候选方案 → 决策 → 后果」记录因果链。

## 内容要求

- 优先记录**为什么**这样决策，而不是复述代码。
- 已经过时的方案要标注「已废弃」并说明原因，避免后来者误用。
- 技术决策发生变化时，更新对应文件，不保留互相矛盾的当前结论。
